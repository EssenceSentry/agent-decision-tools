# Leave a usable handoff

Update the existing record with the last verified result, its artifact or revision, and the action the next person can take now. Preserve a failed attempt when it rules out a plausible next move.

For a partial release, say which outputs can be published, which must be held, and the missing fact that would release each held output. Treat a reassuring cross-check as optional unless its result could change that action. Read the handoff once as a recipient with access only to the cited records.

For long-running work, keep the owner, remaining allowance and any condition that reopens a decision where the next operator can find them. Use the optional [checkpoint and restore commands](references/compaction.md) when a project needs recovery across context compaction, or the [shortcut scan](scripts/scan_debt.py) when tracking a known limit.
