# Search and transfer sheet

Use the sheet when several superficially similar precedents compete for one experiment.

<a id="cross-field-search"></a>

## Generate search terms from relationships

Write who acts, what information they see, what constrains them and what improves. Before retrieving, name different fields that might contain that relation. Search the relation in their own terms, check a primary example and rank by mechanism fit and constraints. Keep a negative search result when it rules out a promising route.

<a id="library-contract"></a>

## Try the reference implementation at its hardest boundary

Use one representative call, the awkward input and relevant failure behavior. Check the maintained version, migration burden and fallback. If an input that the source assumes impossible is routine in the target, restrict the transfer or reject it.

<a id="think-far-analogy-ideation"></a>

## Write a transfer sheet

For each candidate record source domain and evidence, source relation, corresponding target relation, candidate design, necessary condition and a discriminating test. Deliberately try a distant mechanism if nearby precedents repeat the same premise. A failure of one necessary relation is enough to discard an attractive analogy. Evidence from human creativity studies motivates a search and does not predict the agent’s success.
