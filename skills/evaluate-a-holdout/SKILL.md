# Honor a prospective test

Before opening the holdout, fix the population, sign or direction, baseline, horizon, metric and threshold that would change the decision. Include costs and guardrails that affect the action. State what can be decided if a required observation is missing.

Apply the frozen rule once the agreed evidence is available. Report the decisive estimate with its uncertainty and the resulting action. If a failed gate already settles a conjunctive rule, identify any unevaluable gate without delaying the decision. An attractive reversal or subgroup found after inspection is a new hypothesis for fresh evidence.

Where a pivotal number is in doubt, recompute it from the raw inputs through a route that could disagree. [Bounded trials and independent recomputation](references/field-notes.md)
