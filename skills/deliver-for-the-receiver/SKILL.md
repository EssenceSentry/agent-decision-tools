# Make the decision actionable

Lead with the action the recipient can take now, its owner and timing. State the evidence and the condition that would change the recommendation in the recipient’s units.

For a spending decision, name the alternative, the incremental benefit needed to cover the commitment, its time horizon and any separate guardrails. Lower unit cost can coexist with lower total margin. Translate the result into the decision the budget owner will actually make.

For a technical delivery, identify the usable artifact, entry point, input and expected result. For each missing fact, name the specific action it blocks and what can proceed now. Read back the decision using only the message and the material the recipient will have. [Decision memo and technical handoff examples](references/field-notes.md)
