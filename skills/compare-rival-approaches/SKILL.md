# Choose between credible alternatives

Compare the contenders on the outputs the user actually needs. Mark extrapolations. Identify the credible alternative that would most change the decision.

For models, ask what each forces to be equal, zero or constant. Which restrictions follow from the input definition or a known property of the whole system? Which describe only one contribution to the measured outcome? For a consequential unsupported restriction, fit the smallest extension that relaxes it while preserving established constraints. Check whether the correction keeps its direction and a practically meaningful size when influential observations are withheld. Where coverage permits, test toward the requested boundary.

For designs, put the same caller through a normal operation and the failure on which the alternatives disagree. Trace who owns the invariant and what the caller observes.

Give the requested result and the assumption that decided it. If the evidence leaves the choice open, quantify the rival result and identify the observation that could settle it. [More comparison techniques](references/field-notes.md)
