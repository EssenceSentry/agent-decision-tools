# Updating grounded inputs before forward sampling

**Update the prior with this case's observations.** Treat the reference class or elicited range as the prior and what was observed in this case as data. Each piece of evidence belongs on one side only. For a rate, a prior `beta(a, b)` with `h` hits in `n` trials becomes `beta(a + h, b + n - h)`. For a count per unit of exposure, a prior `gamma(k, 1 / t)` with `x` events in `e` units becomes `gamma(k + x, 1 / (t + e))`. `a + b` is prior effective trial count; `t` is prior exposure in the same units as `e` (the gamma distribution above uses shape and scale). Set them from the size and relevance of the reference class and state them. Report prior and posterior together. To price another observation, check whether any plausible new result could still change the action.
